線形微分方程式 確認レポート

===


線形常微分方程式、特に定数係数斉次形を考える。
f'' + af' + bf = 0 など。 exp tx だと思って解くと、特性方程式が出てくる。
exp αx, exp βx だなとなる。

重解のときは x exp αx もいけるようだ。確認してみよう。 E:=exp αxとしよう
f=xE
f' = E+αxE
f'' = αE + α(E+αxE) = 2αE + α²xE

f'' + af' + bf
= 2αE + α^2xE + a (E+αxE) + bxE
= E (2α + α^2x + a + aαx + bx)
= E (2α + x (α² + aα + b) + a)
= 0

最後は α² + aα + b = 0 と 解と係数の関係: 2α = -a から


単振動: f'' + a²f = 0 (a > 0)
これを単に特性方程式として解くと、x² + a = 0, x = ±ai と虚数解が得られる。
このときは、複素解の場合として処理できて、A cos ax + B sin ax が解となる。

ところで、素直に代入して得られたりするだろうか。
C exp aix = C (cos (ax) + i sin (ax))
どうなのだろう。微妙そうだ。


また、power seriesとして仮定して解くということもできるようだ。


例:
- f' - f = 0  ->  exp
- x(1-x) f'' + (1-x)f' + 1/4 f = 0  ->  超幾何級数
- f'' - f = 0
