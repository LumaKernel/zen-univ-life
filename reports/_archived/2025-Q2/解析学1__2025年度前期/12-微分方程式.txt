微分方程式 確認レポート
今回の授業の内容に関して、面白かった点、より詳しく知りたいこと、難しかったところなどについて記述してください。レポートの形式や文字数などは気にせず自由に記述してください。


基本:
f'=f : C exp
f''=-f : A sin + B cos

f'=2f : C exp 2x

f'/f = a の気持ちになると log が見える。

変数分離形: f' = F(f) G(x)

しかし、少し特殊に、 f' = f G(x) だと、 f = exp(∫G) のような気持ちには、すぐなれそうだ。

一般には ∫ 1/F(y) dy になるのだから、これが解ける前提はありそうだ。

ロジスティック方程式: dN/dt = rN  (f' = rf か)
もしくは r=(a-bN) としてみる。 f'=(a-bf)f
単純に、f'=(1-f)f を考えると、 ∫1/(1-f) df + ∫1/f df = ∫dx
∫1/(1-f) df + ∫1/f df = ∫dx   -log|1-f| + log|f| = x   log|f/(1-f)| = x
f/(1-f)=exp  f=(1-f)exp  f(1+exp)=exp  f=exp/(1+exp)
(積分定数は注意する)

定数変化法: f' + pf = g
f' + pf = 0の斉次形をまず求め、A expなどになったら、Aを関数として解釈して代入して解くとうまくいくらしい。

ロトカ・ヴォルテラ方程式 (Lotka-Volterra)
ロジスティクスの、相互作用版。
N1 = (* - * N2) N1
N2 = (* N1 - *) N2

追う追われる、みたいなグラフになる。
